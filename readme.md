# CounterFact Knowledge Editing Pipeline (GPT-2 Small)

A reproducible pipeline for evaluating single-fact knowledge editing on **GPT-2 small** (`gpt2`) using the **CounterFact** dataset (`azhx/counterfact`) with **ROME** and **MEMIT** via [EasyEdit](https://github.com/zjunlp/EasyEdit).

---

## Repository Structure

```text
.
├── EasyEdit/                          # EasyEdit framework (pinned commit)
│   └── hparams/
│       ├── ROME/gpt2.yaml             # ROME hyperparameters for GPT-2 small
│       └── MEMIT/gpt2.yaml            # MEMIT hyperparameters for GPT-2 small
├── scaled_counterfact_pipeline.py     # Unedited baseline evaluation (500 cases)
├── run_rome.py                        # Single-edit evaluation runner for ROME
├── run_memit.py                       # Single-edit evaluation runner for MEMIT
├── repair_and_align.py                # CSV sanitizer and common-case aligner
├── analyse_results.py                 # Paired statistical tests & bootstrap CIs
├── extra_stats.py                     # Additional diagnostics & runtime checks
└── requirements.txt                   # Python dependencies
```

## Configuration Notes

* **Model:** `gpt2` (downloaded automatically from Hugging Face Hub or loaded from `./hugging_cache/gpt2`).
* **Dataset:** `azhx/counterfact` (500 sampled evaluation cases, deterministic seed `42`).
* **Windows Compatibility:** If running on Windows with CPU-only PyTorch, ensure `num_workers=0` in EasyEdit's `layer_stats.py` data loader to avoid multiprocessing `PicklingError`.
* **Hyperparameters:**
  * ROME config: `EasyEdit/hparams/ROME/gpt2.yaml` (`layers: [5]`, `v_num_grad_steps: 20`, `v_lr: 5.0`, `mom2_adjustment: false`)
  * MEMIT config: `EasyEdit/hparams/MEMIT/gpt2.yaml` (`layers: [5]`, `v_num_grad_steps: 20`, `v_lr: 0.5`, `mom2_adjustment: false`)

## Execution Workflow

### Step 1: Run Unedited Baseline ($C_0$)
Generates `scaled_baseline_results.csv` across the 500 sampled CounterFact cases:
```bash
python scaled_counterfact_pipeline.py
```

### Step 2: Run ROME Editing ($C_1$)
Applies each edit independently starting from clean GPT-2 weights and writes to `rome_results.csv` (supports automatic resume by `case_id`):
```bash
python run_rome.py --hparams EasyEdit/hparams/ROME/gpt2.yaml
```
*(Optional: add `--limit 5` for a quick smoke test before running all 500 cases.)*

### Step 3: Run MEMIT Editing ($C_2$)
Applies each edit independently starting from clean GPT-2 weights and writes to `memit_results.csv`:
```bash
python run_memit.py --hparams EasyEdit/hparams/MEMIT/gpt2.yaml
```

### Step 4: Repair & Align CSV Outputs
Sanitizes unescaped quotes/newlines in generated text columns and aligns common `case_id` rows across `scaled_baseline_results.csv`, `rome_results.csv`, and `memit_results.csv`:
```bash
python repair_and_align.py
```
This outputs:
* `baseline_common.csv`
* `rome_clean.csv`
* `memit_clean.csv`

### Step 5: Run Statistical & Diagnostic Scripts
Computes paired bootstrap confidence intervals, exact McNemar tests, Wilcoxon signed-rank tests, and Holm-adjusted $p$-values:
```bash
python analyse_results.py
python extra_stats.py
```

## Output CSV Schema

Each evaluation CSV (`scaled_baseline_results.csv`, `rome_results.csv`, `memit_results.csv`) contains the following columns:

| Column | Type | Description |
| :--- | :--- | :--- |
| `case_id` | `int` | Unique CounterFact instance identifier |
| `relation_id` | `str` | Wikidata relation ID (e.g., `P101`, `P17`) |
| `subject` | `str` | Subject entity string |
| `prompt` | `str` | Target cloze prompt |
| `target_new` | `str` | Counterfactual target object |
| `target_true` | `str` | Original ground-truth object |
| `target_new_preferred` | `int` | `1` if $\log P(\text{target\_new}) > \log P(\text{target\_true})$, else `0` |
| `paraphrase_new_preferred` | `float` | Mean preference score across paraphrase prompts |
| `neighbourhood_true_preferred` | `float` | Mean retention score across neighbourhood prompts |
| `greedy_answer` | `str` | Short greedy continuation generated by the model |
| `greedy_equals_true` | `int` | `1` if `greedy_answer` starts with `target_true`, else `0` |
| `edit_seconds` | `float` | Wall-clock runtime (in seconds) for the single edit |
